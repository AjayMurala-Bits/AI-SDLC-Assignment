# AI SDLC Assignment 1

This repository contains both assignment parts.

## Part-1A — Movie Ticket Booking CLI

Part-1A is complete for its approved scope. It contains:

- A Python command-line movie ticket booking application with local JSON storage.
- Two fixed shows (`S1`, `S2`), ten seats per show, and pricing of INR 200 per seat.
- Commands for listing shows, viewing seats, booking, viewing bookings, and cancellation.
- Validation that prevents double booking and partial multi-seat bookings.
- Separated CLI, booking logic, and storage modules under `Part-1A/src/`.
- Specification-derived unit tests under `Part-1A/tests/`.
- Ruff, Bandit, and unittest validation through `Part-1A/.harness/run_checks.ps1`.
- Workflow, initial-generation, repair, harness-result, and final-generation evidence under `Part-1A/evidence/`.
- A completed student-reported manual demonstration and recorded ACCEPT decision.

See the [Part-1A README](./Part-1A/README.md) and [quickstart](./Part-1A/specs/001-movie-ticket-booking/quickstart.md).

Demo video: [Part 1A - Movie Booking CLI.mp4](./Part%201A%20-%20Movie%20Booking%20CLI.mp4).
