# AI SDLC Assignment

This repository contains both assignment parts.

## Part-1A — Movie Ticket Booking CLI

Part-1A is complete for its approved scope. It contains the Python command-line
movie ticket booking application, specification-derived tests, validation
harness, workflow evidence and the recorded student decision.

See the [Part-1A README](./Part-1A/README.md) and its quickstart. The demo video
is [Part 1A - Movie Booking CLI](./Part%201A%20-%20Movie%20Booking%20CLI.mp4).

## Part-1B — Movie Review Summarizer

Part-1B contains the approved movie-review summarizer implementation and
evaluation harness.

- Ollama is the default local provider at `http://127.0.0.1:11434/v1` using
  `llama3.2:latest`. No credential is required or stored.
- The OpenAI provider remains available through private environment setup.
- Offline tests and mock evaluation are not live model evidence.
- Live execution uses the documented harness after dataset approval and freeze.
- Application and judge retries remain zero; prompts, thresholds, dataset and
  initial snapshot are preserved.
- The first complete source is preserved before validation-driven repairs.

Part-1B evidence is preserved under `Part-1B/evidence/`; student narrative logs
and acceptance decisions must reflect actual work and observations.
