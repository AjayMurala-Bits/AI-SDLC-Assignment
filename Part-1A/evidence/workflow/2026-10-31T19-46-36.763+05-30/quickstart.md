# Quickstart and Acceptance Validation

## Planned prerequisites

- Python 3.11+ is available.
- Ruff and Bandit are installed for development validation.
- No application code or store file is assumed to exist before the first run.

## Planned validation command

Run the single mandatory gate from the repository root:

```text
powershell -NoProfile -ExecutionPolicy Bypass -File .harness/run_checks.ps1
```

The harness will run Ruff, Bandit, and `python -m unittest discover -s tests -v`,
capture each result, and save a new run folder under `evidence/harness-results/`.

## Acceptance-to-test mapping

| Acceptance area | Planned test coverage |
|---|---|
| Shows and initial availability | `test_booking.py`: fresh state lists S1/S2 and A1–A10 available for each. |
| Successful booking and exact price | `test_booking.py`: book S1 A1/A2, assert active booking, INR 400, and unavailable seats only on S1. |
| Double-booking prevention and show isolation | `test_booking.py`: reject S1 A1 twice while allowing S2 A1. |
| Invalid input and atomicity | `test_booking.py`: reject unknown show, invalid/repeated/empty seats, and mixed available/unavailable requests with unchanged state. |
| View booking | `test_booking.py` and `test_cli.py`: assert show, seats, total, and status by ID; unknown ID is a clear error. |
| Cancellation | `test_booking.py`: release seats, retain cancelled record, and reject repeat/unknown cancellation without changes. |
| Persistence and next ID | `test_storage.py`: write, reload, and continue IDs without resetting records. |
| Invalid or unreadable storage | `test_storage.py`: assert an error and unchanged file rather than silent reset. |
| CLI command contract | `test_cli.py`: exercise all five commands and non-zero error handling. |

## Evidence requirements

Each actual harness invocation gets a new timestamped folder with start/end
timestamps, exact commands, exit codes, stdout, stderr, and overall PASS/FAIL.
The narrative `evidence/harness-log.md` remains separate and is not generated by
the harness.
